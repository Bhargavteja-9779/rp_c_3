To make the method usable outside this study, we release it as a small Python package with a command-line tool, `loom-triage`. A user trains a model on labelled recordings and then runs it on new recordings with a chosen review budget or confidence threshold:

    loom-triage fit --train train.csv --model model.pkl
    loom-triage run --model model.pkl --input new.csv --budget 0.2 --out queue.csv --report report.html

The output lists, for every recording, the predicted class, the confidence, the leverage ratio h(x)/$h_{\mathrm{ref}}$ as an "unusualness" score, the decision (automatic or review) and, optionally, a jackknife+ prediction set. A self-contained HTML report summarises the run for the person who handles the review queue. The same functions are available in Python through a scikit-learn style `LOOMClassifier`. The tool needs no GPU and no validation data, and training takes about as long as fitting MiniRocket with ridge regression. As an end-to-end check we ran the tool on ECG5000 with real electrode-motion noise from the MIT-BIH Noise Stress Test Database added to 30 % of the test recordings at 6 dB. With a 20 % review budget, the review queue contained 53 % of the noisy recordings, and the error rate of the automatic decisions was 2.3 %, against 6.1 % for all decisions together. The package, its tests and the demo are part of the code repository.
