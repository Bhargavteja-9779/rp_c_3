# Manuscript

* `latex/` — **current submission version** (Springer Nature sn-jnl template). `bash latex/build.sh` builds
  `main.pdf` and `supplement.pdf` (with layout checks in `build_report.txt`); `python3 latex/make_word.py`
  makes the Word version; `bash latex/make_submission.sh` assembles `../submission/LOOM_Submission.zip`.
  All numbers come from `../code/tables/macros.tex` (generated by `code/experiments/aggregate.py`).
* `build/` — earlier pandoc/Markdown pipeline (legacy; superseded by `latex/`). Kept for history;
  `build/references.json` remains the verified bibliography source for `latex/make_bibtex.py`.
* `Final_Manuscript.*`, `alternative_ESWA/` — outputs of the legacy pipeline (earlier title); not part of the submission.
* `refs/` — reference verification records.
